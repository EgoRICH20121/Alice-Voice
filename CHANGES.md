# Что изменено

Переменные Vercel: GEMINI_API_KEY, SERPER_API_KEY (как раньше).
Новая необязательная: GEMINI_FALLBACK_MODEL (по умолчанию gemini-3.1-flash-lite) —
запасная модель, на которую переключаемся при 503/429/таймауте основной.
В vercel.json добавлен регион fra1 (ближе к России, чем регион Vercel по умолчанию);
если Gemini из этого региона недоступен для вашего ключа — удалите строку "regions".
