# Что изменено (вторая итерация)

## Переменные окружения
Без изменений: GEMINI_API_KEY, SERPER_API_KEY, GEMINI_MODEL (необязательно).
Необязательная: GEMINI_FALLBACK_MODEL (по умолчанию gemini-3.1-flash-lite).

## Краткий и подробный режим
- По умолчанию: 2–5 предложений, не больше ~600 символов (промпт + maxOutputTokens 350).
- «Расскажи подробно / объясни подробнее / разверни / пошагово / детально / расскажи всё» —
  подробный режим (maxOutputTokens 600, ответ до ~850 символов: лимит Диалогов — 1024).
- Режим хранится в session_state (`detail: 1`) и действует, пока тема не сменилась
  (эвристика: короткое уточнение или общие слова с предыдущими репликами;
  «сменим тему», новый вопрос без общих слов, поиск/погода/память сбрасывают режим).
- «Короче / кратко / в двух словах / без подробностей» — сразу короткий режим.
- «Объясни подробнее» / «короче» без вопроса пересчитывает предыдущий вопрос.

## session_state ≤ 1 КБ
Диалоги ограничивают session_state 1 КБ. Раньше история (до 16 реплик по 700 символов)
в этот лимит не помещалась. Теперь реплики сжимаются (90/130 символов) и самые старые
отбрасываются, пока JSON не станет ≤ 900 байт: помнится примерно 1–2 последних обмена.

## Поиск
- Поиск запускается только для погоды, новостей, спорта, «в интернете / поищи / курс валют /
  актуальн…»; «найди разницу…» и технические вопросы идут сразу в Gemini.
- Новости и общий поиск: Serper → пересказ Gemini строго по найденным данным; если в тексте
  появились числа, которых нет в источниках, или не хватило времени — ответ собирается без Gemini
  из заголовков, дат и фрагментов с пометкой, что это не полный текст.
- Погода: без Gemini. Из сниппета берутся только температура, состояние, ветер; проверяются город
  и день (прогноз на завтра не выдаётся за текущую погоду). Нет надёжных данных — так и говорим.
- «Поиск недоступен» (сбой Serper) отличается от «ничего не найдено».
